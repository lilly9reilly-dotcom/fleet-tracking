# الكوثر — تطبيق أندرويد

تم تحويل `index.html` إلى تطبيق APK عبر Apache Cordova.

## ملف التثبيت

- `AlKawthar.apk` في المجلد الرئيسي للمشروع
- أو `android-app/AlKawthar-debug.apk`

## التثبيت على الجوال

1. انقل ملف الـ APK إلى هاتف أندرويد
2. افتح الملف من مدير الملفات
3. اسمح بتثبيت التطبيقات من مصادر غير معروفة إن طُلب منك
4. ثبّت وافتح **الكوثر**

> هذا إصدار debug للاستخدام الشخصي. لنشره على Google Play يلزم توقيع release.

## إعادة البناء بعد تعديل index.html

من مجلد `android-app` شغّل:

```powershell
.\build.ps1
```

## المتطلبات (مثبتة مسبقاً على هذا الجهاز)

- Node.js / npm
- JDK 17
- Android SDK
- Gradle
